# Story 01: Forgot Password Form Layout

**Epic**: Epic 02 - Password Recovery and Security UI  
**Assigned Member**: NM Rubasinghe (UI/UX Design & Documentation)  

---

## 🔍 1. Requirement Gathering & Business Rules
- **Target Persona**: Users requesting a password reset link.
- **Core Requirements**:
  - Email input form with dispatch trigger.
  - Confirmation alert instructing user to check their email inbox.

---

## 🎨 2. UI/UX Design Specifications
- **Layout & Visuals**:
  - Minimalist card dialog centered on screen.
  - Back to login navigation button.

---

## 📝 3. User Story
*As a* user who forgot their password  
*I want to* enter my email address to request a reset link  
*So that* I can regain access to my account  

---

## ✅ 4. Acceptance Criteria
- [x] Email input field with syntax validation.
- [x] Displays confirmation dialog upon sending reset email.
